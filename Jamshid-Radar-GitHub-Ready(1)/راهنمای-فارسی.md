# راهنمای سریع فارسی — جمشید (JAMSHID)

این پروژه برای نصب روی سرور اوبونتو و نمایش لحظه‌ای وضعیت شبکه همان سرور طراحی شده است. پنل فارسی راست‌به‌چپ، با رنگ‌های چهارگانه لوگوی گوگل و طراحی شیشه‌ای است. کد منبع، رابط کاربری، نصب‌کننده Nginx، سرویس systemd و ابزار تغییر نام کاربری و رمز عبور در فایل ZIP قرار دارند.

## مراحل نصب

۱. قبل از هرچیز یک زیردامنه مجزا مانند `jamshid.example.com` بسازید که رکورد A آن به IP عمومی سرور ایران اشاره کند. اگر رکورد AAAA ساخته‌اید باید IPv6 واقعاً قابل دسترسی باشد. پورت TCP 80 برای دریافت گواهی و 443 برای مشاهده پنل باید از بیرون قابل دسترسی باشند.

۲. ZIP را در سرور باز کنید، وارد پوشه پروژه شوید و اجرا کنید:

```bash
sudo bash scripts/install.sh
```

در مراحل نصب، از شما آدرس دامنه، یک بخش دلخواه URL به‌عنوان Web Path، نام کاربری و رمز عبور (حداقل ۱۲ کاراکتر) پرسیده می‌شود. مثال فرضی URL:

```text
https://jamshid.example.com/radar-x8n6p9/
```

۳. پس از نصب، SSL را بگیرید:

```bash
sudo bash scripts/enable-ssl.sh jamshid.example.com
sudo certbot renew --dry-run
```

تا پیش از فعال‌شدن HTTPS وارد پنل نشوید. در صورتی که Let’s Encrypt نتواند از اینترنت به پورت 80 سرور ایران وصل شود، از اعتبارسنجی DNS-01 ارائه‌دهنده DNS استفاده کنید. اسکریپت همراه پروژه فقط روش HTTP-01 با Nginx را خودکار انجام می‌دهد.

## مدیریت از ترمینال لینوکس

```bash
sudo jamshidctl passwd           # عوض کردن رمز عبور
sudo jamshidctl username         # عوض کردن نام کاربری
sudo jamshidctl rotate-sessions  # خروج همه نشست‌های قبلی
sudo jamshidctl show             # نمایش پیکربندی بدون رمز و کلید نشست
sudo systemctl status network-radar
sudo journalctl -u network-radar -n 80 --no-pager
```

## اضافه کردن مقصد خارجی (VPS آلمان، ترکیه، سوئیس و سایر کشورها)

```bash
sudo nano /etc/network-radar/config.json
```

در آرایه `targets` رکوردهایی به این شکل اضافه کنید:

```json
{"id":"germany-1","name":"Germany / My VPS","country":"DE","host":"203.0.113.20","port":443,"enabled":true}
```

**آی‌پی بالا صرفاً مثال مستندسازی است؛ IP یا دامنه واقعی سرور خود را جایگزین کنید.** سپس:

```bash
sudo systemctl restart network-radar
```

تست اتصال به آن مقصد از **خود سرور ایران به سمت مقصد** انجام می‌شود، پینگ و دسترسی TCP با هم اشتباه گرفته نمی‌شوند. این پروژه به‌تنهایی نمی‌تواند از خارج ایران به سرور شما اتصال ورودی برقرار کند و وضعیت آن را بررسی کند؛ آن مورد به عامل بررسی مستقلی روی سرور خارجی نیاز دارد.

## امکانات نسخه فعلی

- گزارش لحظه‌ای TCP/UDP Listener و آدرس Bind، IPv4/IPv6، DNS، رابط‌ها و مسیر پیش‌فرض
- تست IPv4، IPv6، DNS، HTTPS، ICMP و یک مسیر نمونه UDP با STUN
- سنجش تأخیر TCP و Ping به مقاصد اینترنتی و سرورهای خارجی دلخواه
- شناسایی بهترین‌تلاش سرویس‌های شناخته‌شده VPN مثل Xray، WireGuard، 3x-ui، OpenVPN، sing-box و IPsec از systemd
- نمودار ترافیک و وضعیت CPU/RAM/دیسک
- احراز هویت و HTTPS با نشست دارای کوکی Secure/HttpOnly/SameSite؛ تغییر رمز از لینوکس

**توجه:** یک پورت Listening الزاماً از اینترنت قابل دسترس نیست. همچنین فعال‌بودن Xray به‌معنی سالم‌بودن کانفیگ VLESS/Reality نیست. برای پایش دقیق سلامت کاربران VPN و دسترسی از کشورهای مختلف، به نسخه بعدی با Agent خارجی و اتصال امن به API سرویس‌ها نیاز است.

برای توضیحات فنی و محدودیت‌ها فایل `README.md` را هم بخوانید.

- نام سامانه: **جمشید (JAMSHID)**
- **تم تیره (پیش‌فرض):** رنگ زغالی `#202124`
- **تم روشن:** رنگ استخوانی `#F5F1E8`
- کلید تغییر تم (ماه / خورشید) در صفحه ورود و نوار بالای داشبورد وجود دارد؛ انتخاب شما در همان مرورگر ذخیره می‌شود.
- متن‌های فارسی با **Vazirmatn** نمایش داده می‌شوند؛ فونت با اتصال مرورگر به Google Fonts بارگذاری می‌شود. اگر دسترسی به آن محدود باشد، Tahoma جایگزین می‌شود. کارکرد پنل وابسته به فونت نیست.
- مسیرهای داخلی قبلی مانند `network-radar.service` برای سازگاری با نسخه قبل حفظ شده‌اند؛ در نصب جدید فرمان `jamshidctl` نیز در دسترس است.

## ارتقا از نسخه ۱.۰ بدون تغییر رمز و SSL

پس از تهیه نسخه پشتیبان از `/etc/network-radar/config.json`، در پوشه نسخه جدید:

```bash
sudo cp /etc/network-radar/config.json /root/network-radar-config.backup.json
sudo cp -a app /opt/network-radar/
sudo systemctl restart network-radar
sudo ln -sfn /usr/local/sbin/radarctl /usr/local/sbin/jamshidctl
```

**توجه:** اسکریپت `install.sh` برای نصب جدید است و به‌صورت عمدی در صورت وجود نصب قدیمی اجرا نمی‌شود.
